你是一个资深全栈/算法工程师，请为我实现一个「爆款短视频拆解与复刻」工具的 MVP（后端为主），要求可运行、结构清晰、可扩展。

# 0. 目标
实现一个本地可跑的服务：上传短视频（<=60s），自动拆解成镜头/分镜表格 + 指标分析 + 结构模板；并支持输入新品类/产品/卖点生成“跨品类改编脚本”。暂不做真正的视频生成（可以预留接口）。

# 1. 技术栈约束
- Python 3.11+
- FastAPI（HTTP API）
- Celery + Redis（异步任务队列；如果你觉得 RQ 更简单也可，但必须异步）
- SQLite（MVP 落库）+ 本地磁盘（存视频、音频、关键帧）
- FFmpeg（抽音频、抽帧）
- 镜头切分：优先使用 PySceneDetect；若不可用则用 OpenCV 直方图差异备选
- ASR：faster-whisper（优先）或 openai-whisper（备选）
- OCR：PaddleOCR（可选项，若安装复杂可以先做“接口+占位实现”，但 pipeline 要支持开启/关闭）
- LLM：不强依赖外部 API；先实现一个“规则优先”的镜头分类与描述生成（Hook/Product/Detail/Usage/CTA），并预留 llm_client.py 适配器（例如 OpenAI/本地 LLM），用 env 配置开关

# 3. MVP 的算法要求（务实可用）
3.1 镜头切分
- 输出 shots: [{idx, t_start, t_end, keyframe_path}]
- 关键帧：每段抽中间帧（或最清晰帧），保存到 data/frames/{video_id}/shot_{idx}.jpg

3.2 ASR
- 产出带时间戳的 segments: [{t_start,t_end,text}]
- 再聚合到 shot：把落在镜头时间段内的文本拼接成 shot.transcript_text

3.3 产品露出检测（MVP 可用的简化版）
由于没有产品图，先用“图像变化+字幕关键词”的启发式：
- 若镜头 transcript_text 或 OCR_text 中包含疑似产品词（可从全片最高频名词/品牌词猜测；或允许用户在 adapt 输入 product_name 后回填）
- 或者镜头画面变化较小且中心区域出现明显包装（用简单的边缘密度/颜色块面积阈值近似）
输出 product_present(bool) + conf(0~1)
要求：逻辑写清楚、参数可配、并在 README 说明这是 MVP 简化方案

3.4 镜头分类（规则优先）
基于文本关键词 + 时序位置 + product_present：
- Hook：开头 0~5s 且包含痛点/问题/夸张词（例如 “你是不是/还在/尴尬/发臭/难搞/别再”）
- CTA：包含 “下单/链接/评论区/关注/私信/领券/带走/购买”
- Usage：包含步骤/动作词（“倒入/喷/抹/搓/冲/用法/一次/两步”）
- Detail：包含机制/细节/对比/倍率/成分（“放大/细节/原理/配方/提升/5倍”）
- Product：product_present 为真或包含产品名/类目词
输出 label + scene_desc（一句话）

3.5 指标与建议
- first_product_time：第一个 product_present 镜头的 t_start
- product_exposure_time：所有 product_present 镜头时长之和
- product_ratio：product_exposure_time / total_duration
- suggestions（规则）：
  - first_product_time > 3s -> “建议3秒内加入产品画面…”
  - product_ratio < 0.3 -> “产品露出偏少…”
  - CTA 不存在 -> “建议补充行动引导…”
  - Hook 过长且无产品 -> “开场过长且无产品露出…”

3.6 结构模板 blocks
按 label 聚合为 Hook/Product/Detail/Usage/CTA 五段：
- 每段：包含 shot_ids、t_range、summary（拼接该段描述+文本的简短总结）、count、total_time

3.7 跨品类改编（不依赖外部 LLM）
实现一个 deterministic 的改写器：
- 输入 new_category、product_name、selling_points[]
- 按 blocks 生成新脚本：
  - Hook：生成 1~2 句痛点+悬念
  - Product：1 句产品定位 + 1 句核心卖点（从 selling_points 取）
  - Detail：2~3 句解释/对比（套模板）
  - Usage：2~3 句用法步骤（套模板）
  - CTA：1 句引导行动
同时输出每段 recommended_shot（文字建议：如“开箱特写/使用演示/前后对比”）
后续会换成 LLM，所以结构要可替换（Adapter 模式）
